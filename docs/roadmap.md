# 下一步实验路线

1. 先完成数据授权/分组审计和不可变模型登记，在独立 real 环境用 10–30 张图验证 PaddleOCR 检测识别与本地 Qwen 服务；实测资源、服务 seed、warmup、token 上限和失败情况，保留误读样例。
2. 建立分组固定的低光照/正常光照对照数据，训练/验证/测试不共享源图；缓存全量 OCR/VLM。加入 OCR-only、VLM-all、随机路由、oracle 效益上界，比较 A/B 和预算曲线。用验证集选参数，冻结测试集。
3. C 加亮度分位数、对比度、模糊、噪声等图像特征；做置信度校准、特征消融、同预算 CER、按退化强度/文字大小分层、跨设备/跨数据集测试。检验是否只学会“暗图”数据偏差。
4. D 从检测区域开始，实现裁剪坐标/阅读顺序/重叠合并、区域效益与成本估计，加入全局预算约束。对比图像级同预算路由，分析漏检区域与路由不可见性。
5. 真实端到端计时应包含 OCR、特征、路由、crop/编码、网络、VLM、合并和冷启动。风险评估加入不可见文字人工标注、空白背景、序列截断、遮挡及高置信度错误；报告置信区间和源图级 bootstrap。

当前不实现 C/D 算法、不启动长期训练队列、不部署服务。上述实验结果与 NSFC 科学问题的关系需在真实证据出现后论证。
